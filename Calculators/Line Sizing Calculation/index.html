Line Sizing Calculator

Pressure drop for a single process line — Darcy–Weisbach for liquid, isothermal compressible pipe flow with the acceleration (kinetic-energy) term for gas/vapor (Crane TP-410 / GPSA form) — plus the API RP 14E erosional velocity limit for liquid/multiphase service. Enter the pipe's internal diameter directly; this tool does not embed an NPS/schedule lookup table.

Pipe internal diameter is a direct input, not looked up. Take it from your project piping class / ASME B36.10 table for the selected NPS and schedule — an embedded NPS→ID table risks a wrong transcribed value for some size/schedule/material combination, so none is built in here. No fitting-K table either: add elbows, tees, valves, etc. as an equivalent length directly (commonly ~20–40 pipe diameters each — confirm against project piping data or a vendor K-table), same honest-scoping pattern used across this suite. For the gas tab, the isothermal compressible form with the ln(P1/P2) acceleration term is the correct short-line method — Weymouth/Panhandle-type correlations do NOT apply; those are long-distance gas-transmission fits. The API RP 14E erosional velocity check is liquid/multiphase-specific per the standard's own scope — it is not evaluated on the gas tab, which instead carries a Mach-number velocity guideline. Not a substitute for a full line hydraulic study, a project piping specification, or sign-off by a licensed engineer.

READY LINE CHOKED OR NEAR-SONIC
Liquid — Darcy–Weisbach: v = Q/A, A = πD²/4; Re = ρvD/μ (μ converted cP→Pa·s ×1e-3); Darcy friction factor f = 64/Re for Re < 2300 (laminar), else Swamee–Jain explicit fit to Colebrook–White: f = 0.25 / [log₀₀(ε/(3.7D) + 5.74/Re0.9)]². ΔP = f·(L+Lfit)/D · (ρv²/2).
API RP 14E erosional velocity: imperial form Ve[ft/s] = C/√ρm[lb/ft³]. Converting units (1 ft/s = 0.3048 m/s, 1 lb/ft³ = 16.0185 kg/m³) gives ρm[lb/ft³] = ρm[kg/m³]/16.0185, so Ve[m/s] = 0.3048·√16.0185 · C / √ρm[kg/m³]. The leading coefficient (0.3048×√16.0185) is computed numerically in code, not hardcoded — see the derived value reported in the console/verification. C = 100 (continuous, solids-free/non-corrosive) or 125 (intermittent) per API RP 14E; higher values require project-specific justification. This check is liquid/multiphase-specific per the standard's own scope — not evaluated on the gas tab.
Typical velocity guideline (informational only): ~1–2 m/s pump suction, ~2–3 m/s pump discharge/general process liquid — a commonly cited rule of thumb, not a hard limit; varies by project specification.
Gas/vapor — isothermal compressible pipe flow with acceleration term (Crane TP-410 / GPSA Engineering Data Book, short process piping — Weymouth/Panhandle do NOT apply): P1² − P2² = ṁ²·Z·Rspec·T / A² · [ f·L/D + 2·ln(P1/P2) ], all pressures absolute (Pa), Rspec = R/MW, R = 8314.462618 J/(kmol·K), A = pipe cross-sectional area. Here P1 (upstream) is known and the equation is solved forward for P2 (downstream) — the reduced form of the identical equation used in the companion Flare Header Backpressure tool, which instead knows P2 and solves for P1.
Solved for P2 (P1 known) by fixed-point iteration with 0.5 under-relaxation from the initial guess P2 ≈ √(P1² − base·fL/D) (ln term ignored), re-including the 2·ln(P1/P2) correction each pass, to |ΔP2| < 1e-6 bar or 100 iterations (capped so it always terminates); a non-positive radicand at any pass is reported as choked/cannot pass this flow.
Reynolds number: Re = 4ṁ/(π·D·μ). Darcy friction factor (Swamee–Jain, no iteration needed): f = 0.25 / [log₀₀(ε/(3.7D) + 5.74/Re0.9)]².
Gas velocity & Mach: reported at both ends using ρ1 = P1·MW/(Z·R·T) and ρ2 = P2·MW/(Z·R·T); v = ṁ/(ρ·A). Velocity increases along the line as the gas expands toward the lower-pressure end. Mach number is evaluated at the outlet (lowest pressure, highest velocity, since ṁ and A are constant along the pipe): Mach = v2/√(k·Z·Rspec·T). Mach ≥ 0.9, or a non-converging solve, is flagged as choked/near-sonic rather than reporting a falsely-precise number. A separate informational badge bands Mach: <0.3 OK, 0.3–0.5 CAUTION, >0.5 WARN (same bands as the companion Noise Screening tool, for consistency) — no API RP 14E erosional check is applied here, as that check's scope is liquid/multiphase, not gas.
Z-factor: Dranchuk–Abou-Kassem (DAK) correlation with Standing pseudo-criticals from gas gravity, direct Pc/Tc entry, or ideal gas — same basis as the companion Flare Header Backpressure and BDV Sizing tools, evaluated once at the upstream pressure and temperature.
Scope note: single line, steady-state, constant fluid properties along the line (isothermal for the gas case). No NPS/schedule lookup and no fitting-K table are embedded — pipe ID and equivalent lengths are direct, project-sourced inputs. Not a substitute for a full line hydraulic study, a project piping specification, or sign-off by a licensed engineer.
