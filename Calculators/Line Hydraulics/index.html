Line Hydraulics Calculator

Darcy-Weisbach pressure drop for single-phase flow, or a simplified homogeneous + Lockhart-Martinelli estimate for two-phase flow. Screening-level only — validate against detailed models for critical designs.

Inputs — Single-Phase Flow

Default ≈ commercial steel (1.5×10⁻⁵ m).
Choosing an option sets the angle field below to a preset (0° for Horizontal, 90° for Vertical). This is just a shortcut — you can still edit the angle afterward for any in-between (sloped) pipe run.
Enter the pipe's angle measured from horizontal: 0° = fully horizontal (no elevation change), +90° = straight up (flow rises, e.g. bottom-to-top), −90° = straight down (flow falls). Elevation difference is calculated automatically as Pipe length × sin(angle) and used in the elevation pressure-drop term.

Minor-loss K factors for valves, elbows, tees, etc.
How is ΣK calculated?

Look up the K value for every fitting, valve, and transition in the line (from Crane TP-410, GPSA, or vendor data) and add them all together. ΣK is a single dimensionless number you calculate by hand and enter above — the calculator does not derive it for you.

FittingTypical K
Standard 90° elbow0.3 – 0.9
Long-radius 90° elbow0.2 – 0.3
Tee, flow through run0.2 – 0.6
Tee, flow through branch1.0 – 1.8
Gate valve, fully open0.1 – 0.2
Globe valve, fully open4 – 10
Check valve (swing)2 – 2.5
Sudden contraction0.1 – 0.5
Pipe entrance (sharp)0.5
Pipe exit1.0
Example: 4 standard elbows (K≈0.75 each) + 1 gate valve (K≈0.15) + 1 tee run-through (K≈0.4) → ΣK = 4×0.75 + 0.15 + 0.4 = 3.55 — that's the number to enter above.

Darcy-Weisbach: ΔP = f·(L/D)·(ρv²/2)  |  f: laminar 64/Re, turbulent Swamee-Jain  |  Minor: ΔP = K·(ρv²/2)  |  Elevation: ΔP = ρ·g·Δz
Elevation difference Δz is derived from pipe orientation as Δz = Pipe length × sin(angle of inclination) — not entered directly. This is an added convenience over a direct Δz input; set the angle to 0° for a purely horizontal run (Δz = 0).
Two-phase: homogeneous mixture density 1/ρ_mix = x/ρ_g + (1−x)/ρ_l, then single-phase ΔP scaled by Lockhart-Martinelli multiplier φ² (C ≈ 20).
Erosional velocity (API RP 14E): Ve = 1.22·C/√ρ (m/s, ρ in kg/m³) — an empirical guideline, not a hard physical or safety limit. C = 100 is the baseline for continuous service; other values shown are commonly used industry adjustments for intermittent, corrosive, or solids-laden service, not values API RP 14E itself prescribes precisely. Two-phase uses the computed mixture density.
Scope note: this tool handles incompressible liquid and simplified liquid+gas two-phase flow only. It does not perform full compressible gas-flow line sizing (density change along the line, Mach number, Weymouth/Panhandle-type equations) — that is a distinct calculation not covered here.
