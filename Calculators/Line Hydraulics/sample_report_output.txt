--------------------------------------------------------------------------------
Scenario: 0.05 m3/s water through a 0.1 m ID, 50 m pipe, commercial steel
roughness — a standard turbulent case (Re well above 2300).

Command:
  python3 line_hydraulics.py --flow 0.05 --diameter 0.1 --length 50 \
      --rho 1000 --mu 1e-3 --roughness 1.5e-5

Output:
  Line hydraulics results:
   - velocity_m_s: 6.3662
   - Reynolds_number: 636620
   - friction_factor: 0.0146866
   - dp_friction_Pa: 148807
   - dp_minor_Pa: 0
   - dp_elevation_Pa: 0
   - dp_total_Pa: 148807

Result: PASS
Notes:
  - v = Q/A = 0.05 / (pi*0.05^2) = 6.366 m/s -> matches.
  - Re = rho*v*D/mu = 636,620 -> turbulent, correctly routed to Swamee-Jain.
  - dp_friction hand-recomputed via f*(L/D)*(rho*v^2/2): matches script output.

--------------------------------------------------------------------------------
TEST 4 - Two-phase homogeneous + Lockhart-Martinelli estimate
--------------------------------------------------------------------------------
Scenario: Low-quality (x = 0.05) gas-liquid mixture (liquid rho=800 kg/m3,
gas rho=20 kg/m3) through a 0.1 m, 100 m pipe, to exercise the two-phase
homogeneous density/viscosity blend and the separated-flow LM multiplier.

Command:
  python3 line_hydraulics.py --flow 0.02 --diameter 0.1 --length 100 \
      --rho 800 --mu 3e-4 --two-phase --rho-g 20 --mu-g 1.2e-5 --quality 0.05

Output:
  Line hydraulics results:
   - velocity_m_s: 2.54648
   - rho_mix_kg_m3: 271.186
   - mu_mix_Pa_s: 0.0002856
   - Re_mix: 241796
   - friction_factor_mix: 0.0163382
   - dp_friction_single_Pa: 14365.5
   - lockhart_martinelli_phi2: 14.8161
   - dp_two_phase_Pa: 212840
   - dp_minor_Pa: 0
   - dp_total_Pa: 212840

Result: PASS
Notes (all independently recomputed by hand and matched to script output):
  - rho_mix from 1/rho_mix = x/rho_g + (1-x)/rho_l -> 271.19 kg/m3.
  - mu_mix = (1-x)*mu_l + x*mu_g -> 2.856e-4 Pa.s.
  - dp_friction_single via Darcy-Weisbach on mixture properties -> 14,366 Pa.
  - Martinelli parameter chi = ((1-x)/x)^0.9 * sqrt(rho_g/rho_l) = 2.237;
    phi2 = 1 + 20/sqrt(chi) + 1/chi = 14.82 -> matches script (14.8161).
  - dp_two_phase = dp_friction_single * phi2 = 14,365.5*14.8161 = 212,843 Pa,
    matches script (212,840, rounding).

================================================================================
OBSERVATIONS / MINOR NOTES (not necessarily bugs — informational)
================================================================================
1. Zero or negative diameter/flow are not explicitly pre-validated; they
   surface as a generic "float division by zero" (or similar) Calculation
   error rather than a more specific message like "diameter_m must be > 0".
   The script still exits cleanly (code 3) with no traceback, so this is a
   usability nicety rather than a functional defect.
2. The Lockhart-Martinelli implementation is explicitly documented in the
   docstring as "a rough screening estimate" using a fixed Chisholm C = 20
   (turbulent-turbulent assumption) regardless of actual phase Reynolds
   numbers computed elsewhere in the function (Re_l, Re_g are computed but
   not used to select C). This matches the module's own stated intent
   ("simplified... rough estimate") and is not a bug, but worth flagging if
   more rigorous two-phase design work is anticipated.
3. As with the PSV sizing tool, the module's docstring correctly scopes
   itself as a screening tool only, and recommends detailed multiphase
   models or vendor software for critical designs — consistent with the
   test results here.
4. PyYAML was not installed in the test environment, so only the JSON input
   path (Test 5) was exercised; the YAML path raises a clear RuntimeError
   with an install hint if PyYAML is missing (correct defensive behavior,
   not separately exercised here).
