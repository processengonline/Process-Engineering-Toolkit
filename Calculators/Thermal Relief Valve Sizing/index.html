Thermal Relief — API 521 Practice

Thermal Relief Valve Sizing Calculator

Sizes the relief orifice for a blocked-in, liquid-full line or exchanger exposed to a heat source — thermal expansion of the trapped liquid, not a fire or vapor-generation case. Required relieving rate is derived from first principles (dV/dt = β·Qheat/(ρ·Cp)) and sized through the same API 520 liquid orifice equation and API 526 orifice table used for PSV liquid relief.

Not a substitute for certified sizing. This tool covers the classic "blocked-in liquid, external heat input" thermal relief case only. It does not address: vapor generation / two-phase relief, autorefrigeration, the case where the blocked-in fluid can flash or boil before reaching relief conditions, control-valve/utility failure scenarios, or fire relief (use the PSV Orifice Sizing calculator's fire-case method for that). Thermal expansion coefficient β and specific heat Cp are both temperature- and composition-dependent — the values you enter should come from fluid property data or a process simulator at the actual trapped condition, not a single generic number. For an actual EPC deliverable you still need manufacturer-certified Kd/Kv data, a full line/equipment isolation review confirming every blocking scenario is captured, and review/stamp by a licensed engineer.

READY — VOLUME-INDEPENDENT
Why the blocked-in volume never appears above: for a trapped liquid of volume V heated at rate Q_heat, dV/dt = V·β·(dT/dt) and dT/dt = Q_heat/(m·Cp) = Q_heat/(ρ·V·Cp) — substituting gives dV/dt = β·Q_heat/(ρ·Cp). The V in "V·β" and the V in "ρ·V·Cp" are the same trapped volume, and they cancel exactly. Thermal relief sizing therefore depends only on the heat input rate and the fluid's thermal/physical properties — not on how much liquid is trapped between the block valves. This surprises a lot of junior engineers the first time they see it, but it is a genuine and useful result: you do not need to know (or conservatively estimate) the isolated line/exchanger volume to size a thermal relief valve correctly.
Governing case: a liquid-full line, exchanger shell/tube side, or vessel is isolated between block valves (or an inadvertently closed valve leaves it blocked-in) while exposed to an external heat source — a hotter process stream on the other side of an exchanger, ambient/solar gain on an outdoor line, steam tracing left on, etc. With no vapor space to absorb the expansion, pressure can rise rapidly and the line can rupture unless relieved. This is the classic API 521 "liquid thermal expansion" case, distinct from fire (vapor-generation) relief.
Derivation (SI, first principles): dV/dt = V·β·(dT/dt); dT/dt = Q_heat/(m·Cp), m = ρ·V ⇒ dT/dt = Q_heat/(ρ·V·Cp). Substituting: dV/dt = V·β·Q_heat/(ρ·V·Cp) = β·Q_heat/(ρ·Cp) — V cancels. Required relieving volumetric flow Q_relief (m³/s) = β·Q_heat/(ρ·Cp); required mass flow = ρ·Q_relief. This tool works directly in SI and does not use the API 521 imperial "500" constant form.
Heat input: either entered directly in kW, or computed as Area (m²) × absorbed solar flux (W/m²) for an exposed-surface solar gain case. The solar flux value is always user-entered against your project's basis of design — this tool does not hardcode a "design solar flux" figure.
Orifice sizing (reused verbatim from the PSV Orifice Sizing calculator, liquid path): A(in²) = Q(gpm)/(38·Kd·Kw·Kc·Kv) × √(G1/ΔP(psi)), G1 = ρ/1000, ΔP = P1−P2, solved iteratively for the Reynolds-number-dependent viscosity correction Kv (Kv = 1 below ~100 cP; Kv = 1/(0.9935 + 2.878/√Re + 342.75/Re^1.5) above it, floored at 0.3). Converted to/from SI for display.
Relieving pressure: P1 = (P_set + 1.01325 bar atm) × (1 + overpressure), overpressure 10% single PRV / 16% multiple PRVs, per API 520/521 (non-fire).
API 526 orifice designation: computed area rounded up to the next standard API RP 526 (5th ed.) effective area — D 0.110 in² · E 0.196 · F 0.307 · G 0.503 · H 0.785 · J 1.287 · K 1.838 · L 2.853 · M 3.60 · N 4.34 · P 6.38 · Q 11.05 · R 16.00 · T 26.00 (letter "I" omitted). Thermal relief flows are typically very small — most thermal relief cases round up to the smallest standard orifice, "D" (0.110 in²); a non-standard tiny orifice is essentially never fabricated for this service. Confirm against the current edition and manufacturer catalog before ordering.
