Restriction Orifice Sizing — Process Letdown / Flow-Limiting Service

Restriction Orifice Sizing Calculator

Sizes a thin sharp-edged concentric restriction-orifice (RO) plate to take a target pressure drop at a target flow — pump minimum-flow protection, gas letdown stations, flare KO-drum inlet restriction, compressor recycle restriction, and similar EPC flow-limiting service. This is not a custody-transfer metering-run design.

Not a substitute for a certified RO plate design. Liquid sizing uses the ISO 5167-2 thin-orifice equation with either a fixed, user-entered Cd (the normal EPC practice for restriction orifices) or the full Reader-Harris/Gallagher correlation for corner taps only — flange taps and D–D/2 taps are not implemented. Gas/vapor sizing uses the same choked/subcritical compressible-orifice physics as API 520 PSV sizing, with Cd in place of Kd and no Kb/Kc correction. The cavitation and multi-stage-noise flags are screening indicators only, not the certified assessments: a severe liquid service needs vendor/IEC 60534-8-4-style multi-hole anti-cavitation trim design, and a severe gas letdown case needs an IEC 60534-8-3 aerodynamic noise calculation. For an actual EPC deliverable you still need: confirmed process conditions across the full turndown range, a metallurgy/erosion check on the plate and downstream piping, vendor plate design (bore edge geometry, thickness, tab/handle, RF or RTJ carrier flange rating), and sign-off by a licensed engineer.

Liquid (ISO 5167-2 thin-orifice form, solved for β): qm = (Cd/√(1−β⁴))·(π/4)·d²·√(2·ΔP·ρ), β = d/D, solved by bisection on β ∈ (0.05, 0.95) since β appears inside Cd when the ISO correlation basis is used. qm = Q·ρ/3600 from the entered volumetric flow.
Reader-Harris/Gallagher Cd (ISO 5167-2, corner taps only, L1 = L2 = 0): ReD = 4qm/(πDμ); A = (19000β/ReD)^0.8; Cd = 0.5961 + 0.0261β² − 0.216β⁸ + 0.000521(10⁶β/ReD)^0.7 + (0.0188+0.0063A)β^3.5(10⁶/ReD)^0.3 + (0.043+0.080e−10L1−0.123e−7L1)(1−0.11A)(β⁴/(1−β⁴)) − 0.031(M2′−0.8M2′1.1)β^1.3, with L1 = 0 and M2′ = 0 for corner taps (both correction terms vanish identically). A small-bore correction of +0.011(0.75−β)(2.8−Din) is added when D < 71.12 mm (2.8 in).
Permanent (irrecoverable) pressure loss: ΔPperm ≈ ΔP·(1−β²) — the standard thin-orifice approximation. A large fraction of the measured ΔP across a thin orifice is recovered downstream of the vena contracta; this is not the pressure the downstream system actually loses.
Cavitation screening (rule-of-thumb only): P2 = P1−ΔP (abs). FLASHING flagged if P2 ≤ Pv (guaranteed). CAUTION flagged if (P2−Pv) < 0.5·ΔP — the vena-contracta pressure just downstream of a thin orifice runs well below the recovered downstream pressure P2, so a small margin between P2 and Pv is a real risk flag even when P2 itself is comfortably above Pv. This is a screening flag only; a real assessment needs vendor/IEC 60534-8-4-style multi-hole anti-cavitation trim design for severe services.
Gas/vapor (same compressible-orifice physics as API 520 PSV sizing, Cd in place of Kd): choked if P2/P1 ≤ Pc = (2/(k+1))^(k/(k−1)); choked mass flux G = P1·√(k/(Z·Rspec·T1)·(2/(k+1))^((k+1)/(k−1))); A = qm/(Cd·G). Sub-critical uses the standard isentropic expansion form with the same Z, Cd. d = √(4A/π). Rspec = Runiversal/MW, Runiversal = 8314.462618 J/(kmol·K).
Z-factor: reuses the Dranchuk–Abou-Kassem (1975) correlation and Standing pseudo-critical-from-gas-gravity method [Tpc(°R) = 168+325·SG−12.5·SG², Ppc(psia) = 677+15·SG−37.5·SG², SG = MW/28.9647] from the companion Compressor Settle-Out calculator — ideal (Z=1), gas-gravity estimate, or direct Pc/Tc entry.
Multi-stage RO: total pressure ratio is split equally across n stages in series: per-stage ratio = (P2,tot/P1,tot)^(1/n); each stage sized independently for the same mass flow at its own local upstream/downstream pressure (T1 held constant across stages — a screening simplification, not a stage-by-stage energy balance). An advisory badge flags a single stage taking P2/P1 < 0.25 (noise/vibration risk per IEC 60534-8-3 practice, not calculated here) and any stage with β > 0.75 (bore doing little restricting — reconsider staging or pipe size).
Scope note: this sizes the bore only. It does not calculate aerodynamic noise (IEC 60534-8-3), erosion/wire-drawing life, plate thickness/stress, or the downstream piping's noise/vibration response — all required for a severe-service RO before issue for construction. Corner-tap Reader-Harris/Gallagher only; flange taps and D–D/2 taps are not implemented.
