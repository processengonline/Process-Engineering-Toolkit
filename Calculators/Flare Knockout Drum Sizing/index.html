Flare Knockout Drum Sizing Calculator

Sizes a flare knockout (KO) drum for a single, direct-input governing relief case — the largest simultaneous flare load per the plant's relief/flare system study (e.g. total power failure). Gas capacity uses the Souders-Brown vapor-velocity form with a user-set K (default 0.107 m/s, the general no-mist-eliminator value); liquid holdup is sized on a drainage-time basis rather than a short process-separator retention time. Vertical and horizontal orientations are both supported, each with its own governing geometry.

Not a substitute for a certified flare/relief system study. This tool assumes: (1) the governing relief case — gas mass flow, pressure, temperature, and any accompanying liquid carryover — is a direct input you provide from the plant's flare/relief system case study; it does not determine which upset (total power failure, single largest contributor, fire case, blocked flare header, etc.) governs — confirm the case entered below is genuinely the bounding scenario. (2) Gas capacity uses Vmax = K·√((ρL−ρV)/ρV) with K as a direct, editable input (default 0.107 m/s / 0.35 ft/s). KO drums are typically sized without a mist eliminator — fouling/plugging risk during infrequent, potentially dirty, large transient relief events makes mesh pads undesirable — confirm your design K against API 521 §5.7 and project philosophy rather than assuming a mist eliminator is present. (3) API 521's more rigorous method instead derives K from a target droplet diameter (commonly ~300–600 micron) via an iterative terminal-settling-velocity/drag-coefficient correlation; that level of rigor is deliberately not implemented here, given the risk of misremembering the exact drag-coefficient correlation in a screening tool — the Souders-Brown K approach above is the standard simplified equivalent used for first-pass/EPC screening sizing. (4) Liquid holdup is sized on a drainage-time basis, V = Qliquid·tdrain — not a short process-separator retention time — which is what distinguishes a KO drum from a routine separator; tdrain is a direct editable input (default 20 min), confirm against project philosophy and the flare system study. (5) Gas density uses the same real-gas Dranchuk–Abou-Kassem/Standing Z-factor logic as the other tools in this suite; no sour-gas (H₂S/CO₂) correction is applied unless you enter simulator Pc/Tc directly. (6) No inlet-nozzle momentum (ρV²) check, no rigorous droplet-settling verification, no mechanical/vessel-code design, and no two-phase flashing across the inlet device are performed here. For an actual EPC deliverable you still need: the flare/relief system study confirming the governing case, an inlet momentum and vortex-breaker check, a droplet-settling verification if project philosophy requires it, a process-simulator cross-check, and sign-off by a licensed engineer.

Governing Relief Case (Gas)

Total gas mass flow for the single largest/governing relief case at the KO drum inlet (e.g. total power failure, or the single largest contributor per the plant's relief/flare system study). This tool does not determine which case governs.
Not used directly in this Souders-Brown gas-capacity calculation — carried here for documentation/traceability alongside the other governing-case properties (e.g. cross-check against a downstream dynamic relief simulation).
Gas pressure at the KO drum for the governing case — typically close to the flare header design/operating pressure at that load.

Gas Density — Z-Factor Basis

Real-gas Z is solved with the Dranchuk–Abou-Kassem (DAK) correlation, valid for 0.2 ≤ Ppr < 30 and 1.0 < Tpr ≤ 3.0.

Liquid Carryover & Holdup (Drainage-Time Basis)

Liquid flow accompanying the governing gas relief case. Enter 0 for a dry/gas-only relief case — the drum is then sized on gas capacity/entrainment protection alone, with zero liquid holdup volume added.
API 521 §5.7 discusses KO drum liquid holdup based on the time needed to drain liquid before it can carry over to the flare tip, or before operator/pump-out response — commonly cited practice is in the 20–30 minute range, longer for unmanned/remote facilities. Confirm the governing value against project philosophy and the flare system study; this tool does not embed a single fixed standard number.

Gas Capacity — Souders-Brown

KO drums are typically sized without a mist eliminator (fouling/plugging risk during infrequent, potentially dirty/large transient relief events) — confirm the design K against API 521 §5.7 guidance and project philosophy; do not assume a mist eliminator is present unless specifically justified. Default 0.107 m/s (0.35 ft/s) is the general-purpose no-mist-eliminator value commonly cited for vertical vessels.

Vertical Geometry

Height above the liquid high level up to the gas outlet nozzle. Suggested default = max(0.5·D, 1.0 m), computed once from the initial case above — KO drums often want more generous disengagement height than a routine separator, given the large, potentially dirty, transient flows involved; edit freely to match project philosophy.

Horizontal Geometry

Many KO drums operate at a lower normal level (e.g. 20–30%) to reserve vessel volume for the transient liquid surge during a relief event — confirm against project philosophy; 50% is a simplifying default, not a universal rule.

Gas density (real gas): ρV = Pabs·1e5·MW / (Z·R·T), R = 8314.462618 J/(kmol·K); Z from the Dranchuk–Abou-Kassem (DAK) correlation with Standing pseudo-criticals from gas gravity (or direct Pc/Tc entry, or ideal gas). Same method as the other real-gas tools in this suite.
Gas capacity (Souders-Brown, no mist eliminator by default): Vmax(m/s) = K·√((ρL−ρV)/ρV); Qgas(m³/s) = ṁgas/(3600·ρV). K is a direct input (default 0.107 m/s) — see disclaimer above regarding mist eliminators and the more rigorous droplet-target method this tool does not implement.
Liquid holdup (drainage-time basis): Vliquid = (Qliquid/3600)·tdrain(s). Zero liquid carryover is fully supported — the drum then sizes on gas capacity alone.
Vertical orientation: D = √(4·Qgas/(π·Vmax)); liquid holdup height HL = Vliquid/(πD²/4); tan-tan length L = HL + Hvapor-space (vapor/disengagement height is a direct editable input). L/D flagged against a commonly cited vertical KO drum range of ~2.5–5:1 (informational only).
Horizontal orientation (circular-segment geometry): for a normal liquid level fraction φ (0<φ<1, depth h=φ·D), θ = 2·acos(1−2φ); liquid-area fraction of the full circle = (θ−sinθ)/(2π); vapor-area fraction = 1 − liquid-area fraction. Because φ is fixed by the user, the vapor-area fraction is a constant at any D, so D solves directly (no iteration): D = √(4·Qgas/(π·Vmax·vapor-area fraction)). Liquid area at that D = liquid-area fraction·πD²/4; length from liquid holdup L = Vliquid/(liquid area). L/D flagged against a commonly cited horizontal KO drum range of ~2.5–6:1 (informational only, often longer/flatter than a process separator given surge-volume needs).
Operating level note (horizontal): φ = 0.5 is a simplifying default; many KO drums run a lower normal level (e.g. 20–30%) to reserve freeboard for the transient liquid slug during the relief event itself — confirm against project philosophy.
Scope note: this is a screening/pre-sizing tool for a single, user-specified governing relief case and a single liquid phase. It does not perform inlet-momentum (ρV²) checks, rigorous droplet-settling/drag-coefficient sizing, multi-case envelope sizing, or vessel mechanical design.
