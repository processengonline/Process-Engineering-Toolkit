Nitrogen Blanketing Gas Demand & Valve Sizing

Sizes the required nitrogen blanketing (makeup) gas supply rate for a fixed-roof atmospheric or low-pressure storage tank — the in-breathing side of the tank's breathing duty, covering liquid pump-out replacement, thermal (vacuum) in-breathing, and continuous purge — then sizes the blanketing valve/regulator's required flow area for subcritical compressible flow from the N2 supply down to the tank's blanket set pressure.

Scope & limits — read before use. This tool does not embed API 2000 Table 1 thermal in/out-breathing values — you must read the governing thermal in-breathing (vacuum) rate off API 2000 Table 1 for the tank's actual shell capacity and construction (insulated/uninsulated) and enter it directly below; no table lookup is performed automatically. It does not size the tank's separate pressure/vacuum (conservation) vent for the out-breathing / thermal-overpressure case — out-breathing (liquid filling, vapor heating) is a venting duty, not a blanket-gas demand, and is a distinct calculation not covered here. It does not account for flashing or vapor generation from volatile liquids during pump-out — an additional, separate consideration for light/volatile stocks. And it does not replace the vendor's blanketing valve/regulator Cv selection from its published capacity curves per IEC 60534 — the required flow area below is a screening figure for that selection, not a substitute for it.

Part A — Blanketing Gas Makeup Demand

Liquid Pump-Out (Vacuum Displacement)

Maximum volumetric liquid outflow from the tank. Blanket gas must replace this volume 1:1 at vapor-space conditions to prevent vacuum/air ingress. Tank vapor space is close to atmospheric and ambient, so actual m³/hr is taken ≈ Nm³/hr for this screening tool — flashing/vapor generation of volatile liquids is a separate, additional consideration not covered here.

Thermal In-Breathing (API 2000 Table 1)

Read this value directly off API 2000 Table 1 for the tank's actual shell capacity and construction (insulated / uninsulated) — it is a size-dependent, published table value and is not computed by this tool. Enter the governing vacuum (in-breathing) figure for the tank.

Continuous Purge / Sweep (Optional)

Continuous minimum flow to hold slight positive tank pressure and limit air ingress through minor leaks. Typically a small project- or vendor-specified value rather than a first-principles calculation. Leave at 0 if not specified.

Design Margin

Applied to the summed demand (pump-out + thermal + purge) to get the final sized blanketing gas flow, per normal engineering margin practice. 1.1 = +10%. Edit per project spec.

Part B — Blanketing Valve / Regulator Sizing

N2 Supply Conditions

Pressure immediately upstream of the blanketing valve/regulator (downstream of any upstream plant pressure-reducing station). This is a genuinely low-dP control device holding a tank at a few mbar — enter the local trim inlet pressure, not the full plant N2 header pressure.
Default ambient. Override only if a heated/vaporized N2 supply is used.

Tank Blanket Set Pressure

Small positive gauge pressure the blanketing valve maintains in the tank vapor space. API 2000 low-pressure tanks may run up to ≈15 psig (≈1034 mbarg); atmospheric tanks are typically a few mbar to a few inches w.c.

Valve Discharge Coefficient

Assumed/typical value for an orifice-type restriction. Use the vendor's certified Cd once a specific valve/regulator trim is selected.

READY
Blanketing gas demand (in-breathing side only): Qdemand = Qpumpout + Qthermal + Qpurge, then margined design flow = Qdemand × margin factor. Qpumpout is 1:1 volumetric gas replacement of liquid leaving the tank; Qthermal is the API 2000 Table 1 thermal (vacuum) in-breathing rate for the tank's capacity/construction, entered directly by the user; Qpurge is an optional continuous sweep. Out-breathing (liquid filling, vapor thermal expansion) is a venting requirement, not a blanket-gas demand, and is out of scope here — size it separately against the tank's PV/conservation vent.
Valve/regulator sizing — subcritical compressible orifice flow (API 520-style form, reused for this low-dP device): Pratio = Ptank,abs/Psupply,abs; critical ratio Pc = (2/(k+1))k/(k-1). Because the blanketing valve throttles from a supply pressure that is, in absolute terms, close to the tank's near-atmospheric blanket pressure, Pratio is essentially always > Pc and flow is subcritical: term = 2k/(Rspecific·T·(k−1)), part = Pratio2/k·(1 − Pratio(k−1)/k), required Cd·A = ṁ / [Psupply,abs·√(term·part)], required A = (Cd·A)/Cd. Rspecific = R/MW, k = 1.4 and MW = 28.01 g/mol fixed for nitrogen (pure gas, not user-editable); supply temperature is editable for heated/vaporized N2 supply.
Nm³/hr → kg/s conversion: mass flow uses the ideal-gas N2 density at normal reference conditions (0 °C, 1.01325 bar abs): ρN2,N = Pstd·MW/(R·Tstd) ≈ 1.250 kg/Nm³, independent of the site atmospheric-pressure input (which is used only to convert the local gauge pressures to absolute).
Scope note: this tool sizes the blanket-gas demand and the valve's required flow area only. It reports flow area, not Cv — select the actual blanketing valve/regulator from the vendor's published Cv/capacity curve at this differential pressure and flow, per IEC 60534 control-valve sizing practice, which this screening tool does not replicate. The tank's separate pressure/vacuum (conservation) vent for the out-breathing/overpressure case is a distinct calculation (see API 2000) and is not sized here.
References: API Standard 2000 (Venting Atmospheric and Low-Pressure Storage Tanks), IEC 60534 (Industrial-Process Control Valves — Sizing Equations), GPSA Engineering Data Book. Not a certified sizing package — see the note at the top of the page.
