Compressor Surge Margin Calculator

Companion to the Compressor Settle-Out Pressure & Temperature Calculator in this same compressor-station package. Converts current operating mass flow to actual inlet volumetric flow (the aerodynamic flow basis real anti-surge controllers use), speed-corrects a vendor-supplied surge flow point via the standard affinity law, and screens the resulting margin against a required anti-surge control-line setting — including an approximate required-recycle-flow estimate for turndown cases.

Not a substitute for the vendor's certified performance map. A centrifugal compressor's surge line is set entirely by its impeller aerodynamics — inducer/diffuser geometry, speed, and gas properties along that specific machine's flow path — and can only be established from the vendor's shop/site performance test or a CFD-validated performance map. This tool does NOT predict, derive, or estimate a surge point from first principles: you must enter the vendor-supplied surge flow (Qsurge,ref) read directly off the certified map at a stated reference speed — exactly as the FL/xT valve-recovery coefficients in the control valve sizing tool, or the K-factor in the separator sizing tool, are treated as vendor/test-derived inputs elsewhere in this suite. What this tool does do: (1) converts current mass flow, suction pressure/temperature and gas MW to actual inlet volumetric flow using the same real-gas Z-factor method used across this suite; (2) scales the single vendor surge point to the current operating speed via the standard flow-affinity law (flow ∝ speed) — a first-pass screening approximation, not a substitute for the full multi-speed surge control line a real anti-surge controller uses; (3) compares the operating point against a required control margin you set (confirm this against the project's anti-surge control philosophy / vendor recommendation) and, optionally, estimates the extra recycle/spillback flow needed to hold the compressor above that line during a turndown. For an actual EPC deliverable you still need the vendor's certified multi-speed surge/control line, dynamic anti-surge simulation (RCM, valve stroke/response time), and sign-off by the compressor vendor and a licensed engineer.

Gas Properties & Z-Factor Method

Gas Composition

Use the process gas MW at the compressor suction (from simulation/gas analysis).

Z-Factor Basis

Real-gas Z is solved with the Dranchuk–Abou-Kassem (DAK) correlation, valid for 0.2 ≤ Ppr < 30 and 1.0 < Tpr ≤ 3.0.

Suction Conditions & Current Operating Flow

Surge is fundamentally a flow-coefficient (aerodynamic) phenomenon, so anti-surge control uses actual inlet volumetric flow, not mass flow — this suction density conversion is what makes that comparison possible.

Compressor Speed

The speed at which the vendor's surge flow below was read off the performance map. Enter both speeds in the same units — only the ratio N/N_ref is used, so the units themselves are unit-agnostic to the calculation.

Vendor Surge Line Data (Certified Performance Map)

Actual inlet volumetric flow at the surge point, read directly off the vendor's certified performance map at reference speed N_ref above. Direct vendor input only — not computed by this tool.

Anti-Surge Control Margin

Typical anti-surge control line is set 8–12% (flow basis) to the right of the true surge line, to allow for measurement uncertainty, control-loop dynamics, and process upsets — confirm against the project's anti-surge control philosophy / vendor recommendation.
Lowest actual inlet volumetric flow the downstream process can accept (e.g. minimum turndown before recycle/spillback opens). If this is below the compressor's required minimum flow, the difference is the extra recycle/spillback needed at the compressor to stay off the control line while the process only needs this much.

Suction gas density (real gas): ρ1 = P1,abs·1e5·MW / (Z1·R·T1), with P1 in bar abs, T1 in K, R = 8314.462618 J/(kmol·K), MW in kg/kmol. Z1 from the Dranchuk–Abou-Kassem (DAK) correlation (or Z=1 ideal, or a direct simulator override).
Actual inlet volumetric flow: Q_actual (m³/h) = ṁ (kg/h) / ρ1 (kg/m³) — the standard flow-coefficient basis for anti-surge control, since it tracks the aerodynamic operating point independent of gas density changes that mass flow alone does not capture.
Vendor surge point (direct input, not computed): Q_surge,ref (m³/h actual inlet volumetric flow at the surge point) and N_ref (the speed at which it was read off the vendor's certified performance map).
Speed correction (affinity law): Q_surge(N) = Q_surge,ref · (N / N_ref) — flow scales linearly with speed at a fixed point on the map (flow ∝ N, head ∝ N², power ∝ N³, per the standard centrifugal-machine affinity laws), valid for geometrically similar operating points on the same speed-line family. This is a first-pass screening scaling of a single vendor point, not a substitute for the certified multi-speed surge control line a real anti-surge system uses.
Surge margin: Margin (%) = (Q_actual − Q_surge(N)) / Q_surge(N) × 100.
Status: PASS when margin ≥ required control margin; WARN "operating point inside required control margin" when margin is positive but below the requirement; CRITICAL "at or beyond surge" when Q_actual ≤ Q_surge(N) (margin ≤ 0).
Required recycle flow (approximate): Q_min,required = Q_surge(N) · (1 + required margin/100). If the process's minimum achievable flow Q_process,min is below Q_min,required, Required recycle flow = Q_min,required − Q_process,min — the extra recycle/spillback needed at the compressor to stay above the control line even while the downstream process only needs Q_process,min. A real anti-surge recycle valve sizing needs the full recycle-loop hydraulics and dynamic (RCM) response, not modeled here.
Pseudo-critical properties (Standing, sweet/miscellaneous gas systems): Tpc(°R) = 168 + 325·SG − 12.5·SG², Ppc(psia) = 677 + 15·SG − 37.5·SG², SG = MW/28.9647 (relative to air). Enter Pc/Tc directly from a process simulator for sour or non-typical gas mixtures — no Wichert–Aziz correction is applied here.
Compressor map sketch: illustrative only — a simplified, non-data-driven schematic to communicate the margin concept (surge line, control line, current operating point). It is not plotted from the actual vendor performance curves.
