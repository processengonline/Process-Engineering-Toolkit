Flare & Relief Systems — API 521 · Built-Up Backpressure (Tailpipe Hydraulics)

Flare Header Backpressure Calculator

Computes the built-up backpressure generated by one PSV/BDV's own tailpipe — from its outlet flange to the point it ties into the main flare header — using isothermal compressible pipe flow with the acceleration (kinetic-energy) term included (Crane TP-410 / GPSA form). Adds this to a user-supplied superimposed backpressure (the pressure already present at the tie-in from everything else flowing in the header during the governing scenario) to get total backpressure, then checks it against the valve's allowable backpressure limit per API 520/521.

Superimposed backpressure is a direct input here, not calculated. It is the result of a separate, larger flare-header hydraulic network study covering every device relieving simultaneously into the header under the governing case — this tool only resolves the hydraulics of this one device's dedicated tailpipe. The pipe-flow method is the standard short-line isothermal compressible form with the ln(P1/P2) acceleration term retained — Weymouth/Panhandle-type correlations do NOT apply; those are long-distance gas-transmission fits, not valid for short process tailpipes. Temperature is assumed constant along the tailpipe (isothermal simplification — standard for short, well-insulated or bare runs; re-evaluate for unusually long or actively cooled tailpipes). The gas compressibility Z reuses the same Dranchuk–Abou-Kassem/Standing basis as the companion BDV tool, evaluated once at the known tie-in pressure and relieving temperature. Friction factor uses the Swamee–Jain explicit fit to Colebrook–White — no fitting-K table is built in; add elbows/tees as an equivalent length directly (commonly estimated at 20–40 pipe diameters each, confirm against project piping data or a vendor K-table). Not a substitute for a certified flare network hydraulic study or sign-off by a licensed engineer.

Total backpressure: Superimposed (direct input, from a separate flare header hydraulic study) + Built-up (calculated here, from THIS device's own tailpipe only) = P1 (valve outlet pressure).
Built-up backpressure — isothermal compressible pipe flow with acceleration term (Crane TP-410 / GPSA Engineering Data Book, short process piping — Weymouth/Panhandle do NOT apply): P1² − P2² = ṁ²·Z·Rspec·T / A² · [ f·L/D + 2·ln(P1/P2) ], all pressures absolute (Pa), Rspec = R/MW, R = 8314.462618 J/(kmol·K), A = pipe cross-sectional area.
Solved for P1 (P2 known) by fixed-point iteration with 0.5 under-relaxation from the initial guess P1 ≈ √(P2² + ṁ²ZRspecT/A²·fL/D) (ln term ignored), re-including the ln(P1/P2) correction each pass, to |ΔP1| < 1e-6 bar or 100 iterations (capped so it always terminates).
Reynolds number: Re = 4ṁ/(π·D·μ). Darcy friction factor (Swamee–Jain explicit fit to Colebrook–White, no iteration needed): f = 0.25 / [log10(ε/(3.7D) + 5.74/Re0.9)]².
Choking check: Mach number evaluated at the tie-in end of the tailpipe (lowest absolute pressure, hence highest velocity, since ṁ and A are constant along the pipe): v = ṁ/(ρ·A), ρ = P·MW/(Z·R·T), Mach = v/√(k·Z·Rspec·T). Mach ≥ 0.9, or a non-converging solve, is flagged rather than reporting a falsely-precise number.
Allowable backpressure (reused verbatim from the companion PSV Sizing tool): conventional 10%, balanced bellows 35%, pilot operated 50% of set pressure.
Z-factor: Dranchuk–Abou-Kassem (DAK) correlation with Standing pseudo-criticals from gas gravity, direct Pc/Tc entry, or ideal gas — same basis as the companion BDV Sizing tool, evaluated once at the tie-in pressure and relieving temperature.
Scope note: single device, single dedicated tailpipe, single governing relieving case, constant gas properties along the (short) tailpipe. Superimposed backpressure, header sizing, and simultaneous multi-device network hydraulics are outside this tool's scope — obtain those from the project's flare header hydraulic study.
