Liquid (ISA 75.01 / IEC 60534-2-1): Cv = Q · √(SG / ΔP_eff), where ΔP_eff = min(ΔP_actual, ΔP_choked).
Choked/cavitation check: ΔP_choked = FL² · (P1 − FF·Pv); FF = 0.96 − 0.28·√(Pv/Pc). When ΔP_actual ≥ ΔP_choked, flow is choked/cavitating and ΔP_choked is used in place of the actual ΔP (this increases the required Cv vs. using actual ΔP directly).
Gas: Cv = Q / [N9 · Fp · Y · √((x_eff · P1 · ρ1) / SG)].
Expansion factor: Y = 1 − x_eff/(3·Fk·xT), Fk = k/1.4, x_eff = min(x, Fk·xT). When x ≥ Fk·xT the flow is choked (sonic) and Y is floored at 0.667.
Kv shown alongside as Kv ≈ Cv / 1.156 for reference.
FL and xT valve-type presets (globe/butterfly/ball) are typical representative values, not certified — use the manufacturer's actual FL/xT/Fd for final trim selection. This tool does not compute Fp from piping geometry (enter it directly) and does not apply a Reynolds-number/viscosity correction (FR) for laminar or highly viscous liquid service.
