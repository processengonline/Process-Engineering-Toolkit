Blowdown Valve (BDV) Sizing Calculator

Sizes (or checks) a fire-case blowdown/emergency-depressuring orifice against the classic API 521 criterion: reduce vessel pressure to 50% of design pressure, or to 6.9 barg (100 psig) — whichever is lower — within a required time (15 min default). Uses a real-gas initial inventory (Dranchuk–Abou-Kassem Z) with an ideal-gas isentropic blowdown transient, integrated through a compressible-orifice mass-flow model by 4th-order Runge–Kutta.

Not a substitute for a certified depressuring study. This tool uses the standard simplified API 521 screening method: real-gas Z at the initial condition only (Dranchuk–Abou-Kassem) for an accurate starting inventory M0, then an ideal-gas isentropic expansion of the gas remaining in the vessel (ρ∝P1/k) for the blowdown transient shape — the same simplification used in most practical EPC depressuring spreadsheets, valid for lean/dry gases well away from their dew point. For rich or wet gas systems where retrograde condensation during expansion could occur — which governs minimum metal temperature and low-temperature material selection (e.g. LTCS vs. stainless) — this ideal-gas isentropic temperature is not adequate, and a full EOS-based dynamic depressuring run in a process simulator (HYSYS/UniSim, SRK or PR) is required before finalizing material selection. Also assumes constant k and MW through the blowdown (no composition change), the BDV/restriction orifice as a fixed-Cd compressible orifice with no line losses beyond the orifice itself, and a fixed flare-header backpressure P2 (not the real dynamic profile during blowdown). The 50% factor, 6.9 barg floor, and 15-minute time are the classic API 521 defaults — they are editable here because actual project depressuring philosophies vary; confirm against your PFD/cause-and-effect basis. For an actual EPC deliverable you still need: a confirmed isolated-volume takeoff, a flare-header hydraulic study for the real P2 profile, an EOS dynamic simulation for low-temperature material selection, vendor Cv/trim data for the actual valve, and sign-off by a licensed engineer.

Vessel pressure vs. time
Initial inventory (real gas): M0 = P0,abs·1e5·V·MW / (Z0·R·T0), R = 8314.462618 J/(kmol·K); Z0 from the Dranchuk–Abou-Kassem (DAK) correlation with Standing pseudo-criticals from gas gravity (or direct Pc/Tc entry, or ideal gas).
Depressuring target: Pf = min(factor × Pdesign, floor) — API 521 defaults factor = 0.5, floor = 6.9 barg, both editable; required time default 15 min, also editable.
Isentropic ideal-gas blowdown (screening approximation — see disclaimer above): mass remaining M(P) = M0·(P/P0,abs)1/k; vessel temperature T(P) = T0·(P/P0,abs)(k−1)/k.
BDV orifice compressible mass flow (same choked/sub-critical form as API 520 orifice sizing, Cd in place of Kd, no Kb/Kc corrections): choked when P2/P ≤ (2/(k+1))k/(k−1), with G = P·1e5·√[ (k/(Rspec·T))·(2/(k+1))(k+1)/(k−1) ], w = Cd·A·G; otherwise sub-critical, w = Cd·A·P·1e5·√[ (2k/(Rspec·T·(k−1)))·(P2/P)2/k·(1−(P2/P)(k−1)/k) ], Rspec = R/MW.
Time-marching: dM/dP = (M0/(k·P0,abs))·(P/P0,abs)1/k−1; dP/dt = −w(P)/(dM/dP), integrated from P0,abs down to Pf,abs by 4th-order Runge–Kutta at Δt = 0.5 s (hard cap 7200 s so the loop always terminates).
Sizing mode: bisection search on total BDV flow area (per-valve area × number of parallel valves) so the simulated time-to-target converges to the required time, then divided equally across the entered number of parallel BDVs.
Scope note: single isolated vessel/system taken down through one set of parallel BDVs, single fixed backpressure, single gas composition (no flash/two-phase, no composition change through the blowdown). Trains with staged/sequential isolation, or systems with significant liquid inventory that flashes during depressuring, need the same method applied per isolated section, or a full dynamic simulation.
