Separator Sizing — Rev. 1

3-Phase Separator Sizing Calculator

Horizontal gas/oil/water separator sizing using Souders-Brown gas-capacity velocity, Stokes' law droplet settling, and liquid retention-time volume checks. Sweeps trial diameters and selects the smallest-volume feasible design.

Historical note (already fixed everywhere — no action needed): an earlier, non-Python spreadsheet version of this tool computed liquid retention length using an effective liquid area roughly 3× the vessel's true cross-section — a dimensionally impossible result. separator_sizing.py has always used the corrected formula, L_liquid = V_liquid_required / (liquid_area_fraction × A_cross), and this calculator matches it. Results here will run larger than that old spreadsheet for the same inputs — that's expected, not a discrepancy to resolve.

Souders-Brown: V_max = K·√[(ρ_L−ρ_G)/ρ_G]  |  A_gas = Q_gas/V_max, D_min = √(4·A_gas / (π·(1−f_liq)))

Retention volumes: V_oil = Q_oil·t_oil·60, V_water = Q_water·t_water·60  |  Corrected length: L_liquid = V_liquid / (f_liq·A_cross)
Trial sweep: diameters from ⌈D_min/0.05⌉×0.05 upward in 0.05 m steps over a 6 m span; optimal = feasible trial minimizing A_cross × selected length.
When liquid retention time (not gas capacity or L/D) controls the design, A_cross × length is nearly constant across a wide diameter range — several trial diameters can tie to 14+ significant figures. This calculator (and the current separator_sizing.py, after a second bug fix) breaks such ties toward the smallest feasible diameter for a deterministic, physically sensible result — both now select the same D = 2.50 m / L = 12.22 m for the default inputs, rather than the non-deterministic ~2.5–5.6 m the unpatched script could return purely from floating-point rounding noise.
Nozzle momentum sizing: nozzle diameter = √(4Q / (π·V)), V = √(ρV²_limit / ρ) — i.e. each nozzle is sized to the minimum diameter that keeps mixture momentum ρV² at or below the selected limit. Inlet limits (representative industry values, not a single universal code number): None ≈1000, half-open pipe ≈1500, vane-type/Schoepentoeter ≈6000, cyclonic ≈10000 kg/m·s². Gas outlet default 5000 kg/m·s² per typical GPSA guidance (~4500–5400 range). Liquid outlets sized at a flat 2 m/s design velocity (unchanged from the original script). Confirm all limits against your project's actual specification (e.g. Shell DEP, company standard) — cited values vary by source.
