Pipe Wall Thickness — ASME B31.3 Process Piping · Rev. 1

Pipe Wall Thickness Calculator

Sizes straight-pipe wall thickness under internal pressure per ASME B31.3 Eq. 3a (the "Barlow's formula" variant used throughout process piping), then layers on corrosion allowance and pipe-mill manufacturing under-tolerance to get a required nominal thickness — or runs the same equation in reverse to check the maximum allowable working pressure (MAWP) for a known actual wall thickness.

No NPS/schedule table and no material stress table are embedded in this tool — on purpose. Outside diameter (OD) for a given NPS is fixed per ASME B36.10 regardless of schedule — only the wall thickness changes between schedules for the same NPS — so enter the actual OD from B36.10 (or the vendor's mill certificate) directly; transcribing a schedule-to-thickness table here risked a copy error on some size, so it was left out deliberately. Likewise, allowable stress S is material-grade- and temperature-specific per ASME B31.3 Table A-1 — it is not computed or looked up by this tool; enter the actual Table A-1 value for your selected material at design temperature. The S field below defaults to a round placeholder value only, clearly labeled as such. This screens/pre-sizes the straight-pipe wall — it does not cover branch reinforcement, bends, fittings, flanges, or code-required minimum thickness rounding to a purchasable schedule; a licensed engineer must review the final specification.

Required Nominal Thickness

READY
Pressure-design thickness (ASME B31.3 Eq. 3a, straight pipe under internal pressure): t = (P·Do) / (2·(S·E·W + P·Y)), with P and S in consistent stress units (MPa here) and Do/t in mm. Valid for the common case t < Do/6 — the thin-wall badge flags whether this holds for the current inputs; thicker-wall geometries require the Eq. 1b/3b form per B31.3.
Required minimum thickness: tmin = t + c, where c is the corrosion allowance.
Required nominal thickness: tnom = tmin / (1 − mill under-tolerance fraction), accounting for the pipe mill's permitted manufacturing under-thickness (12.5% standard for seamless pipe per API 5L).
MAWP mode — same equation solved algebraically for P: starting from t = (P·Do)/(2·(S·E·W+P·Y)), cross-multiply: 2t(SEW+PY) = P·Do → 2t·SEW + 2t·PY = P·Do → 2t·SEW = P·(Do − 2tY) → P = 2·S·E·W·t / (Do − 2·Y·t), equivalently written P = S·E·W·t / (Do/2 − Y·t). Here t is the pressure-design thickness still available after removing the mill under-tolerance and the corrosion allowance from the actual wall: tavail = tactual·(1 − mill fraction) − c.
Hydrostatic test pressure: Ptest = 1.5 × design/MAWP pressure, the standard ASME B31.3 multiplier — shown as a reference figure only; the actual required test pressure and procedure must follow B31.3 Chapter VI and the governing piping class.
What this tool deliberately does not do: look up OD or wall thickness from an NPS/schedule table (ASME B36.10 — use the actual OD from the spec/mill cert), or look up allowable stress S from a material/temperature table (ASME B31.3 Table A-1 — enter the actual value). Both were left as explicit, clearly-labeled user inputs rather than baked-in tables, to avoid a transcription error going unnoticed for some size or material grade.
Not a substitute for a stamped piping design calculation. Confirm E, W, Y, S, corrosion allowance, and mill tolerance against the project piping class and material specification before use.
