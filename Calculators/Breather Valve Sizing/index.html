Breather Valve Orifice Calculator

Derives the required venting load per API 2000 — normal thermal in/out-breathing, liquid-movement venting, and emergency fire-case venting — then sizes the vent orifice from that load, instead of taking a flow rate as a bare guess.

Not a substitute for certified sizing. Vapor space volume is approximated as the full tank volume (a common, conservative simplification — the true value depends on minimum liquid level). Thermal outbreathing uses a simplified area-based method, not the rigorous 7th-edition equation (which API 2000 keeps separate from the inbreathing equation implemented here). Environmental factor F and the insulation reduction factor Ri are approximate/user-supplied rather than derived from a full insulation model. For an actual EPC deliverable, confirm vapor space volume against the real operating envelope, use the manufacturer's certified valve capacity curve (not just this orifice-equation estimate), and have the venting study reviewed by a licensed engineer against the current API 2000 edition.

Inputs — Normal Venting (API 2000)

Tank & Liquid

Vapor space volume is approximated as the full tank volume (conservative). Shell+roof area uses this height and a flat roof.
Volatile liquids double the pump-in outbreathing rate (co-mingled vapor generation).

Thermal Breathing Basis

Sets the C-factor in the thermal inbreathing equation, per API 2000 Table 2.
1.0 = uninsulated. For insulated tanks, Ri = 1/(1 + h·t/λ), h = 0.7 Btu/hr·ft²·°F — compute separately (API 2000 Eq. 11/12) and enter the result here.

Relief Settings

Outbreathing (pressure) relief setting, gauge. 1 inch W.C. ≈ 2.4884 mbar.

Inputs — Emergency Venting (API 2000, Fire Exposure)

Vertical tanks: shell area up to 30 ft (9.14 m) above grade, excluding the bottom on grade.

Relief Settings

Liquid movement: Inbreathing (pump-out) V_ip = 8.02 × Q_out(gpm) SCFH air. Outbreathing (pump-in) V_op = 8.02 × Q_in(gpm) [non-volatile] or 16.04 × Q_in(gpm) [volatile].
Thermal inbreathing (API 2000 7th ed., Eq. 10): V_IT = 3.08 × C × V_tk(ft³)^0.7 × Ri, C from Table 2 by latitude and vapor-pressure/temperature category.
Thermal outbreathing (simplified/general method): V_OT = 2 SCFH per ft² of total exposed shell + roof area. This is the older simplified table-style relationship, not the rigorous 7th-edition outbreathing equation — for a precise value, consult API 2000 directly.
Fire case (API 2000 Eq. 17, hexane basis): q = 1107 × F × A(ft²)^0.82 (SCFH air). For a non-hexane liquid, q is corrected by × 1336.8/(λ(Btu/lb)·√M).
Orifice sizing: uses the same choked/sub-critical isentropic gas-flow equations as a PSV, with the derived load (converted to mass flow via standard air density ≈ 1.225 kg/m³) as ṁ, valve set pressure (+ 1.01325 bar atmospheric) as P1, and atmospheric backpressure as P2.
Vapor space volume is taken as the full tank volume (π(D/2)²H) — a common conservative simplification; the true value is the volume above the minimum operating liquid level.
