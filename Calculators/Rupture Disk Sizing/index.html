Rupture Disk Sizing — Rev. 1 · API 520 Part I

Rupture Disk Sizing Calculator

Sizes a rupture disk per API 520 Part I in three service configurations — disk alone, disk installed upstream of a PSV (uncertified combination, Kc = 0.9), or disk + PSV tested and certified as a combination (Kc = 1.0) — reusing the literal compressible/incompressible orifice equations, API 526 orifice selection, and burst-pressure manufacturing-tolerance design checks.

Not a substitute for certified sizing. This tool uses the standard API 520 default KRD = 0.62 for an uncertified disk-alone installation, and the standard API 520 combination-capacity factors Kc = 0.9 (uncertified RD+PSV) / 1.0 (certified) when a manufacturer's tested value isn't entered. For the disk-alone case, no backpressure (Kb) or combination (Kc) correction is applied — Kb = Kc = 1.0 — which assumes a short, unrestricted discharge to atmosphere or a properly sized vent header; a long or restrictive downstream tailpipe needs its own separate outlet-piping check, not modeled here. This tool also assumes a single stamped burst pressure drives the relieving-pressure calculation for all three service modes; a real RD-upstream-of-PSV system may set the PSV's own set pressure independently of the disk's burst pressure — confirm against the actual PSV nameplate/datasheet. Burst-pressure manufacturing tolerance, the vessel design-pressure check, and the operating-margin guideline are all general API 520/ASME VIII practice — always confirm the actual tolerance band and margin requirement against the project spec and the disk manufacturer's certified data sheet. For an actual EPC deliverable you still need vendor-certified KRD/Kr and Kc, a full inlet/outlet piping hydraulic study, and review/stamp by a licensed engineer.

Service mode 1 — disk alone: A sized with K = KRD (default 0.62 uncertified, or vendor-certified), Kb = 1.0, Kc = 1.0 (no backpressure/combination correction — see note above). Result reported as bore diameter, rounded UP to the nearest common commercial disk size: 25, 40, 50, 65, 80, 100, 150, 200, 250, 300 mm (≈1, 1.5, 2, 2.5, 3, 4, 6, 8, 10, 12 in). Not sold in API 526 letters.
Service mode 2 — RD upstream of PSV, uncertified combination: PSV's own rated area computed with its own Kd (preliminary 0.975 vapor / 0.65 liquid, or certified) and Kb exactly as the PSV tool, then derated by Kc = 0.9 — required area scales as 1/Kc, i.e. ≈11% larger than the certified case for the same flow. Rounded to the nearest standard API 526 orifice letter.
Service mode 3 — RD upstream of PSV, certified combination: identical to mode 2 but Kc = 1.0 (no derate) — the disk and PSV were tested together as a unit.
Kb (backpressure correction, APPROXIMATE, RD+PSV modes only): 1.0 for pilot-operated and conventional; for balanced bellows this tool holds Kb = 1.0 up to the API 520 Fig. 30 "flat region" threshold (~30/38% gauge backpressure for 10/16% overpressure) then linearly interpolates down to 0.5 at 50% backpressure. This is a curve-fit approximation of the published figure's shape, not the certified 53-point table — use the manufacturer's actual Kb curve for final sizing.
Relieving pressure: P1 = (stamped burst pressure + 1.01325 bar atm) × (1 + overpressure). Overpressure: 10% single device / 16% multiple devices, per API 520/521 non-fire accumulation.
Burst-pressure manufacturing tolerance: actual_tolerance = max(burst pressure × 5%, 0.138 bar [≈2 psi]) — the standard ±5% band (above ~2.8 barg / 40 psig) or the wider absolute ±2 psi band at low burst pressures, whichever is more conservative. Design check: burst + tolerance must not exceed vessel design pressure/MAWP. Operating-margin guideline: burst − tolerance (lower bound) should be ≥ 1.1 × max operating pressure — a general rule of thumb to avoid premature/fatigue failure, not a code-mandated number; confirm the actual required margin against the project spec and disk manufacturer's data.
API 526 orifice designation (RD+PSV modes): computed area rounded up to the next standard API RP 526 (5th ed.) effective area — D 0.110 in² · E 0.196 · F 0.307 · G 0.503 · H 0.785 · J 1.287 · K 1.838 · L 2.853 · M 3.60 · N 4.34 · P 6.38 · Q 11.05 · R 16.00 · T 26.00 (letter "I" omitted). Confirm against the current edition and manufacturer catalog before ordering.
