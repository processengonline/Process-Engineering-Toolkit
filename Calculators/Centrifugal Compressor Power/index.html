Centrifugal Compressor Power & Polytropic Head

Computes shaft power, polytropic head, and discharge temperature for a centrifugal compressor stage (or an equivalent single-body estimate across a multistage train) using the standard GPSA/API 617 polytropic method — real-gas Z-factor via the Dranchuk–Abou-Kassem correlation, a fixed-point closure between discharge temperature and the average compressibility factor, and an isentropic reference figure for comparison. Companion to the Compressor Settle-Out Pressure & Temperature calculator in this same compressor-station package — that tool covers the tripped/equalized case, this one covers normal running duty.

Not a substitute for a certified thermodynamic rating. This tool assumes: (1) a single equivalent polytropic path from suction to discharge conditions — a real multistage machine has interstage cooling/reheat and a slightly different efficiency per wheel, so treat a multistage estimate here as an overall envelope, not a stage-by-stage design; (2) constant k (Cp/Cv) evaluated at suction conditions across the whole compression path, rather than a pressure/temperature-varying real-gas k from an EOS; (3) sweet-gas Standing/DAK correlations unless you enter simulator-derived Pc/Tc directly — no Wichert–Aziz sour-gas (H₂S/CO₂) correction is applied; (4) mechanical losses entered as a fixed kW value rather than pulled from the vendor's mechanical loss curve. For an actual EPC deliverable you still need: a process-simulator (HYSYS/UniSim/PROSIM) rating case with real-gas k and stage-by-stage Z, the vendor's certified performance curve (head, efficiency, and power vs. flow at the actual impeller/gas), driver sizing with adequate margin, and surge/stonewall margin confirmation. Treat this as a rigorous screening tool, not the compressor selection package itself.

Z-Factor Basis

Real-gas Z is solved with the Dranchuk–Abou-Kassem (DAK) correlation, valid for 0.2 ≤ Ppr < 30 and 1.0 < Tpr ≤ 3.0. Z1 (suction) and Z2 (discharge) are each evaluated at their own P,T and then averaged.

Stage-Count Screening

Typical centrifugal impeller capability given practical tip-speed/Mach-number limits is roughly 25–40 kJ/kg per wheel, depending on gas MW and impeller tip speed — this varies significantly by machine design. Treat as a rough screening indicator only; confirm the actual stage count against the vendor's selection.

Polytropic exponent (API 617/GPSA form): (n−1)/n = (k−1)/(k·ηp), solved for n directly from k and ηp — independent of Z.
Discharge temperature: T2(K) = T1(K)·(P2,abs/P1,abs)^((n−1)/n), using the same exponent as above.
Polytropic head: Hp (J/kg) = Zavg·Rspecific·T1(K)·(n/(n−1))·[(P2,abs/P1,abs)^((n−1)/n) − 1], Rspecific = Runiversal/MW, Runiversal = 8314.462618 J/(kmol·K).
Z-factor closure: Z1 is evaluated at suction (P1,T1). Z2 is evaluated at discharge (P2,T2), where T2 itself is a function of the compression path above; the tool fixed-point iterates Zavg = (Z1+Z2)/2 → T2 → Z2 → Zavg for a few passes to converge Z2 and T2 to mutually consistent values (converges immediately to machine precision for this formula set, since T2 depends only on k, ηp and the pressure ratio — the loop exists to keep Z2/Zavg self-consistent with the final T2 and to carry over cleanly if a more elaborate real-gas exponent correction is substituted later).
Gas power: Pgas (W) = ṁ(kg/s)·Hp/ηp. Shaft power: Pshaft = Pgas + mechanical losses.
Isentropic head (reference only): His = Z1·Rspecific·T1(K)·(k/(k−1))·[(P2,abs/P1,abs)^((k−1)/k) − 1]. Reported for comparison — polytropic head is the standard basis for multistage centrifugal machines because it correctly accounts for the reheat between stages that a single isentropic (adiabatic) calculation ignores.
Z-factor — Dranchuk & Abou-Kassem (1975): Z = 1 + (A1+A2/Tpr+A3/Tpr³+A4/Tpr⁴+A5/Tpr⁵)ρr + (A6+A7/Tpr+A8/Tpr²)ρr² − A9(A7/Tpr+A8/Tpr²)ρr⁵ + A10(1+A11ρr²)(ρr²/Tpr³)exp(−A11ρr²), with ρr = 0.27·Ppr/(Z·Tpr) solved implicitly. Constants A1…A11 = 0.3265, −1.0700, −0.5339, 0.01569, −0.05165, 0.5475, −0.7361, 0.1844, 0.1056, 0.6134, 0.7210.
Pseudo-critical properties (Standing, sweet/miscellaneous gas systems): Tpc(°R) = 168 + 325·SG − 12.5·SG², Ppc(psia) = 677 + 15·SG − 37.5·SG², SG = MW/28.9647 (relative to air), converted to K and bar abs for use above. Enter Pc/Tc directly from a process simulator for sour or non-typical gas mixtures — no Wichert–Aziz correction is applied here.
Stage-count screening: suggested minimum stages = ceil(Hp / head-per-stage limit). This is an informational rule-of-thumb indicator, not a pass/fail requirement — actual stage count is set by the vendor from tip-speed, Mach number, and rotordynamic limits for the specific impeller family.
References: API Standard 617 (Axial and Centrifugal Compressors), GPSA Engineering Data Book (compressor and Z-factor methods), Standing, M.B. (1977) Volumetric and Phase Behavior of Oil Field Hydrocarbon Systems, Dranchuk, P.M. & Abou-Kassem, J.H. (1975) Calculation of Z Factors for Natural Gases Using Equations of State, JCPT.
