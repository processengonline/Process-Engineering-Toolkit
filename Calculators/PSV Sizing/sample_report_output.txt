TEST 1 - Gas relief, CHOKED flow (CLI flags, bar pressures)
--------------------------------------------------------------------------------
Scenario: Propane-like vapor relief, 10 bar(a) -> 1 bar(a), well below the
critical pressure ratio, so flow should choke at the orifice.

Command:
  python3 psv_sizing.py --phase gas --mass-flow-kg-s 5 \
      --inlet-pressure-bar 10 --outlet-pressure-bar 1 \
      --temperature-K 350 --molecular-weight 44 --gamma 1.3

Output:
  PSV sizing results (screening):
   - area_m2: 0.00214119
   - diameter_m: 0.0522135
   - diameter_mm: 52.2135
   - choked: True
   - notes: Choked flow (critical) assumed

Result: PASS
Notes:
  - Critical pressure ratio Pc = (2/2.3)^(1.3/0.3) = 0.5457
  - Actual ratio P2/P0 = 1/10 = 0.10  ->  0.10 < 0.5457, correctly choked.
  - Independently recomputed mass flux G and area A by hand (see Verification
    Note): matched script output to full displayed precision
    (A = 0.0021412 m^2, d = 52.21 mm).

--------------------------------------------------------------------------------
TEST 3 - Liquid relief, volumetric flow input
--------------------------------------------------------------------------------
Scenario: Hydrocarbon liquid (rho = 850 kg/m3) relief, 12 bar(a) -> 2 bar(a).

Command:
  python3 psv_sizing.py --phase liquid --vol-flow-m3-s 0.05 --rho 850 \
      --inlet-pressure-bar 12 --outlet-pressure-bar 2 --Cd 0.65

Output:
  PSV sizing results (screening):
   - area_m2: 0.00158581
   - diameter_m: 0.0449346
   - diameter_mm: 44.9346

Result: PASS
Notes:
  - deltaP = (12-2) bar = 1,000,000 Pa
  - A = Q / (Cd*sqrt(2*deltaP/rho)) = 0.05 / (0.65*sqrt(2e6/850)) = 0.001586 m^2
    matches script output exactly.

================================================================================
VERIFICATION NOTE - independent hand-check of Test 1 (choked gas flow)
================================================================================
Using the same inputs as Test 1 (P0=1e6 Pa, T0=350 K, M=44, gamma=1.3, Cd=0.9,
m_dot=5 kg/s), the choked mass-flux and area formulas were recomputed
independently in a separate Python snippet outside the module under test:

  R_spec  = R_universal / M = 8314.462618 / 44          = 188.965 J/(kg.K)
  factor  = (2/(gamma+1))^((gamma+1)/(2*(gamma-1)))     = 1.5967
  G_crit  = P0 * sqrt(gamma / (R_spec*T0)) * factor     = 2594.61 kg/(s.m2)
  A       = m_dot / (Cd * G_crit)                       = 0.0021412 m^2
  d       = sqrt(4A/pi) * 1000                           = 52.2135 mm
  Pc      = (2/(gamma+1))^(gamma/(gamma-1))             = 0.5457
  P2/P0   = 0.10  (< Pc, confirms choked flow)

These values match the script's Test 1 output exactly, giving confidence that
choked_mass_flux(), isentropic_mass_flow(), and required_area_for_gas_massflow()
implement the intended isentropic ideal-gas relations correctly.
