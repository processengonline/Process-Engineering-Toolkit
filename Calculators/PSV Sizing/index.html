PSV Sizing — Rev. 3 · API 520/521 Detailed

PSV Orifice Sizing Calculator

Sizes per the literal API 520 Part I equations — Kd, Kb/Kw (backpressure), Kc (rupture disk), Kv (liquid viscosity), and gas compressibility (Z) — with set-pressure/overpressure logic, API 526 orifice selection, multi-valve distribution, and an inlet-line 3% pressure-drop check.

Not a substitute for certified sizing. This tool uses standard API 520 "preliminary sizing" Kd values (0.975 vapor / 0.65 liquid) when a certified value isn't entered, and an approximate Kb/Kw backpressure-correction curve fitted to the shape of API 520 Fig. 30–32 (not the exact 53-point manufacturer-certified table). For an actual EPC deliverable you still need: the valve manufacturer's certified Kd/Kb/Kw from their published capacity data, a full inlet/outlet piping hydraulic study (not just the single-number 3% check below), reaction-force and noise calculations, two-phase/flashing evaluation where applicable, and review/stamp by a licensed engineer. Treat this as a rigorous screening/pre-sizing tool that gets you very close to the final answer and lets you sanity-check vendor quotes — not as the calculation package itself.

Gas/vapor (API 520 physics, first-principles form): choked if P2/P1 ≤ Pc = (2/(γ+1))^(γ/(γ-1)); choked mass flux G = P1·√(γ/(Z·R_specific·T1))·(2/(γ+1))^((γ+1)/(2(γ-1))); A = ṁ / (Kd·Kb·Kc·G). Sub-critical uses the standard isentropic expansion form with the same Z, Kd, Kc, Kb factors.
Liquid (literal API 520 Part I imperial equation): A(in²) = Q(gpm) / (38·Kd·Kw·Kc·Kv) × √(G1 / ΔP(psi)), where G1 = ρ/1000 (specific gravity vs. water), ΔP = P1−P2. Converted to/from SI for display.
Kv (viscosity correction): Re = 2800·Q(gpm)·√G1 / (μ(cP)·√A(in²)); Kv = 1/(0.9935 + 2.878/√Re + 342.75/Re^1.5) for Re > 80 (solved iteratively since A depends on Kv); Kv = 1 for μ < 100 cP; Kv floored at 0.3 for very low Re (formula not valid below this — consult manufacturer data).
Kb/Kw (backpressure correction, APPROXIMATE): = 1.0 for pilot-operated (design-dependent, not derated here) and for conventional (not applicable beyond the ~10% guideline — see badge). For balanced bellows, this tool holds Kb/Kw = 1.0 up to the API 520 Fig. 30 "flat region" threshold (~30/38/50% gauge backpressure for 10/16/21% overpressure) then linearly interpolates down to 0.5 at 50% backpressure. This is a curve-fit approximation of the published figure's shape, not the certified 53-point table — use the manufacturer's actual Kb/Kw curve for final sizing.
Kc (rupture disk combination): 1.0 with no rupture disk upstream; 0.9 when a disk is installed and the combination has no certified value.
Kd (discharge coefficient): preliminary/uncertified values per API 520 = 0.975 (vapor), 0.65 (liquid). Use the manufacturer's certified value whenever available — it changes the required area directly and proportionally.
Relieving pressure: P1 = (P_set + 1.01325 bar atm) × (1 + overpressure). Overpressure: 10% single PRV / 16% multiple PRVs (non-fire), 21% fire case, per API 520/521.
Fire case (API 521 alternative method): Q(Btu/hr) = C·F·A(ft²)^0.82, C = 21,000 (adequate drainage) or 34,500 (inadequate); ṁ = Q(kW)/h_vap(kJ/kg). F values shown are approximate — confirm against API 521 Table 5 for your actual system.
Inlet line check: per API 520 Part II, non-recoverable pressure loss in the inlet piping (equipment to PRV flange) must not exceed 3% of set pressure at relieving flow, to avoid valve chatter and capacity loss. Enter that pressure drop (calculated separately) for a PASS/WARN check.
Multi-valve distribution: if required area exceeds the largest standard API 526 orifice (T, 26.00 in²) and Installation = Multiple PRVs, the load is split across the minimum number of equal-capacity valves so each valve's share fits within a standard orifice.
API 526 orifice designation: computed area rounded up to the next standard API RP 526 (5th ed.) effective area — D 0.110 in² · E 0.196 · F 0.307 · G 0.503 · H 0.785 · J 1.287 · K 1.838 · L 2.853 · M 3.60 · N 4.34 · P 6.38 · Q 11.05 · R 16.00 · T 26.00 (letter "I" omitted). Confirm against the current edition and manufacturer catalog before ordering.
